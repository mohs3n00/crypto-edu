## 1. Quality Standards & Criteria
Every question in the BASMAGA system was audited against seven strict academic and pedagogical criteria:
1. **Academic Authority:** The question premise, options, and answer must directly reflect the primary lecture slides and textbooks without speculation.
2. **Bilingual Clarity:** High-precision English question formulation paired with accurate, natural Arabic technical translation.
3. **Distractor Plausibility:** For MCQs, all 3 incorrect options must represent realistic student traps, common misconceptions, or neighboring cryptographic concepts.
4. **Unambiguous Correct Answer:** There must be exactly one objectively correct answer under mathematical, algorithmic, or standard definitions.
5. **Keyword Extraction Utility:** Important keywords are extracted and displayed in a compact tabular format with Arabic translation and target concept mapping.
6. **Zero Essay Bloat:** Elimination of long redundant essays or unrendered distractor paragraphs to support rapid exam pattern recognition.
7. **Interactive Flow Compliance:** Full support for the 5-stage interactive flow (Question → Options → Student Selection → Reveal Answer → Important Keywords → Next Question).

## 2. Chapter-by-Chapter Quality Verification

### Chapter 1: Concepts, Attacks, Services & Models (23 Questions)
- **Confidentiality vs Integrity vs Availability:** Checked: Unambiguous distinction between disclosure, modification, and denial of access.
- **Active vs Passive Attacks:** Checked: Passive attacks monitor/listen (release of contents, traffic analysis); Active attacks modify/fabricate (masquerade, replay, modification, DoS).
- **X.800 Security Services & Mechanisms:** Checked: Explicit mapping of services (Confidentiality, Integrity, Authentication, Non-repudiation, Access Control) to mechanisms (Encipherment, Digital Signature, Access Control, Data Integrity, Authentication Exchange, Traffic Padding, Routing Control, Notarization).
- **Network Security Model Components:** Checked: 4 components (Security-related transform, Secret info, Transform algorithm, Secure channel) verified against slide 17 diagram.

### Chapter 2: Number Theory & Modular Arithmetic (32 Questions)
- **Divisibility & Euclidean GCD:** Checked: Division algorithm properties, termination condition r_k = 0, and linear combination gcd(a,b) = xa + yb.
- **Modular Arithmetic 8 Properties:** Checked: Additive inverse (n-w), Multiplicative inverse condition gcd(a,n)=1, and modulo algebra laws.
- **Extended Euclidean Algorithm:** Checked: Iterative ladder with invariant [x, y], solving ax + by = gcd(a,b) mod n.
- **Fermat & Euler Theorems:** Checked: Exact boundary conditions: Fermat requires prime p, Euler generalizes to composite n via phi(n).
- **Miller-Rabin Primality Test:** Checked: Base 2 compositeness test, Carmichael pseudo-primes, and error bound (1/4)^k.
- **Chinese Remainder Theorem (CRT):** Checked: Pairwise coprime moduli m_i, unique solution mod M, and speedup for large computations.
- **Discrete Logarithms & Primitive Roots:** Checked: Generator definition, cyclic group of order phi(p)=p-1, and one-way function complexity.

### Chapter 3: Classical Encryption Techniques (22 Questions)
- **Symmetric Model & Kerckhoffs's Principle:** Checked: Security rests entirely on secrecy of the key, not on secrecy of the algorithm.
- **Cryptanalysis Attack Models:** Checked: Ciphertext-only, Known-plaintext, Chosen-plaintext, Chosen-ciphertext exact capabilities.
- **Classical Ciphers (Caesar, Playfair, Hill, Vigenère):** Checked: Playfair 5x5 grid rules (same row shift right, same col shift down, rectangle swap opposite corner); Hill key matrix invertibility mod 26; Vigenère polyalphabetic periodicity.
- **One-Time Pad & Shannon Secrecy:** Checked: True randomness, single use, key length equals message length -> perfect secrecy; cannot be broken even with infinite computing power.
- **Transposition & Steganography:** Checked: Rail Fence zig-zag, columnar permutation with key order, and LSB / watermark concealment.

### Chapter 4: Block Ciphers & DES Architecture (14 Questions)
- **Stream vs Block Cipher Design:** Checked: Continuous byte-by-byte XOR vs fixed-size block transformation; hardware vs software tradeoffs.
- **Shannon's Confusion & Diffusion:** Checked: Confusion conceals key relationship (S-Boxes); Diffusion spreads plaintext statistics (P-Boxes).
- **Feistel Architecture Properties:** Checked: Reversible decryption using identical hardware by reversing subkey order K_16 to K_1.
- **DES Parameters & Key Schedule:** Checked: 64-bit input block, 64-bit key reduced to 56 bits via PC-1, 16 rounds of 48-bit subkeys generated by 1-bit or 2-bit circular left shifts.
- **S-Box 6-to-4 Bit Lookup:** Checked: Outer bits (1 and 6) designate row 0-3; inner bits (2,3,4,5) designate column 0-15.
- **Avalanche, SAC & BIC Criteria:** Checked: SAC: 1 bit flip in plaintext changes each output bit with prob 0.5; BIC: output bit pairs change independently.

### Chapter 7: Block Cipher Operation, 3DES & Modes (15 Questions)
- **Double-DES Meet-in-the-Middle Attack:** Checked: Diffie-Hellman MitM requires 2^56 table lookup reducing 2^112 security to 2^57 effective operations.
- **3DES EDE Architecture:** Checked: Encrypt(K1) -> Decrypt(K2) -> Encrypt(K3/K1); Backward compatibility with single DES when K1=K2=K3.
- **5 NIST Modes of Operation:** Checked: ECB (unsuitable for long messages due to pattern leakage), CBC (chaining with IV, error propagation), CFB (stream mode on ciphertext feedback), OFB (keystream independent of plaintext/ciphertext, zero error propagation), CTR (parallel processing, precomputation, random access).
- **PKCS#7 Block Padding:** Checked: Padding value equals number of pad bytes; always appends a full block (e.g. 8 bytes of 0x08) when plaintext is an exact multiple of block size.

## 3. Answer Key & Clue Table Verification
Every single question in the dataset was compiled with:
1. `correctAnswer`: A single, capital letter (`A`, `B`, `C`, `D`, `True`, or `False`).
2. `importantKeywords`: Array of 1 to 4 essential exam trigger phrases, each with English term, Arabic equivalent, and pointer to target concept.
3. `basmagaRule`: A concise mnemonic rule mapping the primary trigger clue directly to the target concept.
4. `quickReasoning`: A crisp, single-sentence justification in English and Arabic explaining why the answer is correct without unnecessary essay bloat.
